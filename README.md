# IT Support Troubleshooting Portfolio

A beginner service desk project documenting how I investigate and resolve common user issues. All scenarios are simulated in a personal lab; they do not represent employment or production access.

## Goal
Build a repeatable support workflow: gather symptoms, check likely causes, test a fix, verify with the user, and document the outcome or escalation.

## What is here
- `tickets/TKT-001-wifi-connectivity.md` — worked example to reproduce and adapt.
- `templates/ticket-template.md` — blank incident record for your own cases.
- `templates/lab-log.md` — record your setup and evidence.
